# Toledo para Latinos 🇪🇸🌎

Guía de supervivencia bilingüe (español / English) para latinos que llegan a Toledo (España).
PWA instalable, hecha en HTML + JavaScript puro, sin servidor propio. Parte de la serie **Latinos por el Mundo** (Londres, Madrid, Bilbao, Medellín, Miami, Nueva York y Toledo).

**Desarrollada por Vibras Positivas HM — Derechos de Autor Reservados**

🔗 https://haroldco45.github.io/toledo-para-latinos/

## Datos verificados (octubre 2026)

- Bus urbano (Unauto, desde el 1 abr 2026): billete 1,40 €; bonobús 0,51 € (0,38 € empadronados); abono general 27,20 €; Abono Toledano 20,40 €; joven 13,25 €; menores de 15 gratis.
- Festivos de Castilla-La Mancha 2026 (Decreto 44/2025): 2 nov, 8 dic, 25 dic (el 7 dic no es festivo).
- Padrón: Plaza del Consistorio 1, 925 330 300, padron@toledo.es. Extranjería: Ronda de Buenavista 57, 925 989 250. Cruz Roja: Cuesta de los Capuchinos 4, 925 216 060. Cáritas: Vida Pobre 3, 925 224 600.
- Pulsera Turística: 14 €, 7 días, siete monumentos.
- Contenido nacional (papeles, SMI, nacionalidad, CCSE) heredado de Madrid para Latinos, verificado en octubre de 2026.

## Publicar en GitHub Pages

1. Crea el repositorio `toledo-para-latinos` en github.com/haroldco45.
2. Sube los 7 archivos: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `og-image.png`, `README.md`.
3. Settings → Pages → Branch `main` / root → Save.
